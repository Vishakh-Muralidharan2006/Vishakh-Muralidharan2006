## Featured project

### [Burn — AI Agent Kill Switch](https://devpost.com/software/burn-the-ai-agent-kill-switch)
**2nd Place, A10 Track · AWS x A10 Hackathon at Santa Clara University · November 2026**

Burn is a security tool designed to detect credential leaks and help contain compromised AI agents. It combines threat monitoring with response workflows so teams can identify suspicious activity and track containment.

My contributions included:

- Reduced DynamoDB event-record size by **30% across 400 sampled events** by removing unused fields while preserving API compatibility.
- Automated expiration of transient records and cleanup of unused credentials in AWS Secrets Manager, while retaining records needed for security investigations.
- Built React and TypeScript views for monitoring agents, prioritizing alerts, and tracking containment status.
- Presented the system in a live hackathon demonstration.
